# Site da Genesis

Página estática única e autocontida — fontes e logo embutidos, nenhuma dependência externa.
Servida por GitHub Pages. Domínio de destino: **genesislegado.com.br**.

## Estado: preview

O conteúdo ainda está em finalização, por isso o site está **fora do índice dos buscadores**
(`<meta name="robots" content="noindex, nofollow">` e `robots.txt` com `Disallow: /`).

## Como publicar uma atualização

Este `index.html` é **arquivo montado** — não editar aqui. A fonte de verdade e o script de
montagem ficam no kit do operador; editar direto neste repositório faz a próxima montagem
sobrescrever a mudança.

## Domínio

O arquivo `CNAME` está como `CNAME.aguardando-dns`. Renomear para `CNAME` depois que os registros
de DNS apontarem para o GitHub Pages — antes disso, o domínio configurado faria o Pages redirecionar
a URL de teste para um endereço que ainda não resolve.

## Peso e performance

96 KB na primeira carga · LCP de 1,1 s medido em 4G lento com viewport de celular.
